<b>PhoenixFireFightGodot</b>

This is Godot project to use the PhoenixFireFightLibrary project https://github.com/JakeTrans/PhoenixFireFightLibrary

Design to be a top down turn based wargame implementing the Library.

This is a work in progress currently built on  Godot_v4.5.1-stable_mono_win64 and visual Studio

This uses

https://opengameart.org/content/animated-top-down-survivor-player - for Sprites by rileygombart

https://www.newgrounds.com/art/view/hyptosis/tile-art-batch-1 - for terrain by Hyptosis

for art assets
